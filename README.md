## 🛠️ Build from Source

If you want to build the launcher yourself, follow these steps:

### Prerequisites
- [Node.js](https://nodejs.org/) (v20 or higher)
- [pnpm](https://pnpm.io/) (v9 or higher)

### Installation

```bash
# Clone the repository
git clone https://github.com/P00KE00M/Chicken-Luncher.git

# Navigate into the directory
cd Chicken-Luncher

# Install dependencies
pnpm install

# Build the application
pnpm --filter xmcl-electron-app build
```

📥 Download

You can download the latest compiled installers (Windows, macOS, Linux) directly from the GitHub Actions tab or the Releases page.
